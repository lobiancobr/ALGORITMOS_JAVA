# ☕ ALGORITMOS_JAVA

Repositório de apoio às disciplinas introdutórias de programação utilizando a linguagem Java.

O material foi desenvolvido para auxiliar estudantes que estão iniciando seus estudos em lógica de programação, algoritmos e desenvolvimento de aplicações desktop utilizando Java.

As aulas apresentam uma progressão gradual, iniciando com conceitos básicos de entrada, processamento e saída de dados, avançando para estruturas de decisão, repetição, métodos, vetores, manipulação de strings e desenvolvimento de interfaces gráficas com Swing.

Além dos exemplos didáticos, o repositório contém projetos completos utilizados em sala de aula, como um sistema CRUD com persistência em arquivos CSV, simuladores de Mega-Sena e Bingo, além de um painel eletrônico de atendimento desenvolvido com HTML e CSS.

## 🎯 Objetivos
- Aprender lógica de programação utilizando Java;
- Desenvolver algoritmos para solução de problemas;
- Utilizar estruturas de decisão e repetição;
- Criar funções e métodos reutilizáveis;
- Manipular vetores e strings;
- Desenvolver interfaces gráficas com Swing;
- Trabalhar com persistência de dados;
- Implementar aplicações completas de pequeno porte;
- Preparar o estudante para disciplinas posteriores de Programação Orientada a Objetos.

## 🚀 Trilha de Aprendizagem
### 1️⃣ Introdução à Programação

Baseado nos exemplos apresentados por Deitel & Deitel, esta etapa introduz:

- Variáveis;
- Tipos de dados;
- Entrada e saída;
- Operadores;
- Estrutura básica de um programa Java.
### 2️⃣ Estruturas de Controle
- if / else
- switch
- while
- do while
- for
- Validação de dados
### 3️⃣ Métodos
- Criação de funções;
- Parâmetros;
- Retorno de valores;
- Boas práticas de modularização.
### 4️⃣ Vetores e Coleções Simples
- Arrays;
- Percursos em vetores;
- Processamento de dados;
- Exercícios aplicados.
### 5️⃣ Manipulação de Strings e Matemática
- Classe String;
- Métodos úteis;
- Classe Math;
- Cálculos e formatação.
### 🖥️ Desenvolvimento com Swing

Os módulos de Swing são baseados nos exemplos do livro do professor Rui Rossi dos Santos, sendo utilizados para introduzir o desenvolvimento de interfaces gráficas desktop em Java.

## 🎲 Projetos Práticos
### 🎱 Mega-Sena

Projeto de geração de jogos da Mega-Sena utilizando números aleatórios e validações.

Conceitos trabalhados:

- Vetores;
- Sorteios;
- Números aleatórios;
- Estruturas de repetição.
### 🎯 Bingo

Projeto para simulação de sorteios e controle de cartelas.

Conceitos trabalhados:

- Sorteios;
- Estruturas de dados;
- Lógica de jogos.
### 📋 CRUD

Projeto completo de cadastro com operações de:

- Create
- Read
- Update
- Delete

Possui persistência de dados utilizando arquivos CSV, permitindo ao estudante compreender os conceitos fundamentais de armazenamento de dados sem a necessidade de um banco de dados relacional.

**Principais recursos:**

- Cadastro de registros;
- Consulta;
- Alteração;
- Exclusão;
- Gravação em arquivo CSV;
- Leitura dos dados armazenados.
### 📺 Painel de Atendimento

Projeto desenvolvido com HTML e CSS simulando um painel eletrônico de atendimento.

Pode ser utilizado como exemplo de integração entre conceitos de desenvolvimento Web e lógica de programação.

Características:

- Interface simples;
- Exibição de senhas;
- Atualização visual;
- Estrutura HTML/CSS fácil de compreender.
