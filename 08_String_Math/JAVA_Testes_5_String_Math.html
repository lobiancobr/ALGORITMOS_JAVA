📚 Classe String e Classe Math em Java

Classe String: A classe String em Java representa sequências de caracteres. Strings são imutáveis, ou seja, uma vez criadas, não podem ser alteradas. Qualquer operação que modifique uma string retorna uma nova string. Principais métodos:

length() - Retorna o número de caracteres
charAt(int index) - Retorna o caractere na posição especificada
substring(int begin, int end) - Retorna uma parte da string
toUpperCase() / toLowerCase() - Converte para maiúsculas/minúsculas
indexOf(String str) - Retorna a posição da primeira ocorrência
lastIndexOf(String str) - Retorna a posição da última ocorrência
replace(char old, char new) - Substitui caracteres
trim() - Remove espaços em branco no início e fim
toCharArray() - Converte para array de caracteres
equals() / equalsIgnoreCase() - Compara strings

Classe Math: A classe Math fornece métodos para operações matemáticas básicas. Todos os métodos são estáticos, podendo ser chamados diretamente. Principais métodos:

abs(int a) - Valor absoluto
pow(double a, double b) - Potência (a^b)
sqrt(double a) - Raiz quadrada
max(int a, int b) - Maior entre dois números
min(int a, int b) - Menor entre dois números
random() - Número aleatório entre 0.0 e 1.0
round(double a) - Arredondamento
ceil(double a) - Arredonda para cima
floor(double a) - Arredonda para baixo
PI / E - Constantes matemáticas
